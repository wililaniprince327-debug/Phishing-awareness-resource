# Phishing Checklist - Check BEFORE You Click

Ask yourself these 5 questions:

1. Do I know the sender? If NO, STOP.
2. Was I expecting this email? If NO, be suspicious.
3. Does it create urgency or fear? If YES, it is likely phishing.
4. Does the link match? Hover over it. Does it go to the real website? If NO, DO NOT CLICK.
5. Does it ask for password or card number? If YES, it is phishing.

If you are suspicious about any question:
- DO NOT CLICK
- Report to IT
- Mark as Phishing in your email
